# Система управління складом (Warehouse Management System)

Цей проект є лабораторною роботою з дисципліни "#################". Це веб-додаток для автоматизації складського обліку, розроблений на мові Python з використанням фреймворку FastAPI.

## 📋 Основний функціонал

Відповідно до технічного завдання, у системі реалізовано:

* **Облік товарів:** Створення, редагування та видалення товарів (назва, артикул, ціна).
* **Облік складів:** Створення та керування списком складів (назва, адреса).
* **Облік транзакцій:**
    * **Надходження:** Додавання товару на конкретний склад.
    * **Внутрішні переміщення:** Переміщення товарів між різними складами.
    * **Розхід:** Оформлення продажу/списання товару зі складу.
* **Облік залишків:** Відображення актуальної кількості товарів на кожному складі в реальному часі.

## 🛠 Технологічний стек

* **Backend:** Python 3.x, [FastAPI](https://fastapi.tiangolo.com/)
* **Database:** SQLite (використання чистого SQL-синтаксису через модуль `sqlite3`)
* **Frontend:** HTML5, Jinja2 Templates, Bootstrap 5 (для стилізації інтерфейсу)
* **Development:** ООП підхід (розділення логіки на окремі класи менеджерів)

## 🚀 Запуск проекту

### 1. Клонування репозиторію
```
git clone [https://github.com/Samotoshua/accounting_of_goods.git](https://github.com/Samotoshua/accounting_of_goods.git)
cd accounting_of_goods
```

### 2. Встановлення залежностей
Переконайтеся, що у вас встановлений Python. Виконайте команду:

```
pip install fastapi uvicorn jinja2
```
### 3. Запуск сервера
Запустіть локальний сервер за допомогою Uvicorn:

```
uvicorn main:app --reload
```
Після цього додаток буде доступний за адресою: http://127.0.0.1:8000

### 📂 Структура проекту
 * **main.py** - Головний файл додатку, роути FastAPI.
